Mental model

Three levels of computational power

Boolean circuit

Question: What output follows from the current input?

Memory: None

Neural analogy: Feedforward network

Finite automaton

Memory: One of finitely many states

Neural analogy: Recurrent network

Turing machine

Question: What can be computed with writable external memory?

Memory: Unbounded tape

Relation: Automaton + external memory

McCulloch-Pitts neuron

A weighted vote followed by a threshold

s = Σi=1M wixi
y = 1 if s ≥ θ; otherwise y = 0

Inputs xi

Binary facts: each is 0 or 1.

Weights wi

Positive encourages firing; negative inhibits it.

Threshold θ

The minimum weighted sum needed to output 1.

Exam trap: the weighted sum can be 2 or 3, but the neuron’s output is always only 0 or 1.
Review Q30 Theory Q4

Calculation routine

Never guess: use the same four steps

  1. Multiply each input by its weight.
  2. Add the products to obtain s.
  3. Compare using s ≥ θ.
  4. Return the binary output y.

Worked example

x1=0, x2=1; w1=w2=1; θ=1

s=(1)(0)+(1)(1)=1
1 ≥ 1 ⇒ y=1
Review Q30 answer: B (output 1)

Limitation

Why one neuron cannot compute XOR

x1x2XOR
000
011
101
110

A single threshold unit creates one straight decision boundary.

For XOR, the two positive points are diagonally opposite. No one line separates them from both negative points.

XOR and XNOR are not linearly separable, so one threshold neuron is insufficient.

Networks

Multiple neurons solve what one neuron cannot

XOR = (x1 OR x2) AND NOT(x1 AND x2)

Layer 1A

Compute x1 OR x2.

Layer 1B

Compute NOT(x1 AND x2).

Layer 2

AND the two intermediate results.

AND, OR, and NOT are functionally complete, so a suitable network can implement any Boolean function.

Finite automata

A machine with a small, fixed memory

  1. Begin in the start state.
  2. Read one input symbol.
  3. Follow that symbol’s transition.
  4. Repeat until the entire finite string is read.
  5. Accept iff the final state is accepting.

The state is the memory

The machine does not store the whole input. Its current state summarizes only the past information relevant to the task.

next state = f(current state, current symbol)

Theory Q9, Q14 Review Q38

Language and termination

What does the machine accept?

Language

The language is the set of all strings accepted by the machine.

Odd-1s examples: 1, 10, 01, 111, 11010.

Finite-automaton languages are called regular languages.

Infinite ordinary input

The machine decides only when the input ends.

If the string never ends, it continues changing states and never produces the ordinary final accept/reject decision.

Passing through an accept state early is not enough. Acceptance depends on the final state after the entire finite input.
Theory Q7, Q8, Q10, Q11 Review Q38

Counting with finite state

Multiples of 3 require only three states

Let each state remember the number of 0s modulo 3:

  • q0: remainder 0 — accepting
  • q1: remainder 1
  • q2: remainder 2

Reading 0 advances q0→q1→q2→q0. Reading 1 loops.

How to identify the language

  1. Determine what each state summarizes.
  2. See which symbols change that summary.
  3. Interpret the accepting state.

Designing an automaton

Accept exactly 101 — and nothing else

q0 --1→ q1 --0→ q2 --1→ qA

Each state means “this much of 101 has been matched.”

  • q0: nothing matched
  • q1: matched 1
  • q2: matched 10
  • qA: matched exactly 101

The missing piece: sink state

Every wrong symbol goes to a rejecting sink qD.

Any extra symbol after qA also goes to qD.

qD loops on both 0 and 1.

A chain showing only 1,0,1 is an illustration, not a complete DFA, unless all omitted transitions are defined.

Limits of finite memory

What finite automata can and cannot remember

Can recognize

  • Odd/even count
  • Count modulo 3
  • Ends with 01
  • Contains 101
  • At least three a’s

Cannot generally recognize

  • Arbitrarily balanced parentheses
  • 0n1n for arbitrary n
  • Arbitrary palindromes
  • Exact unbounded counts

A finite number of states can remember only a finite set of summaries.

From finite automaton to Turing machine

External writable memory changes the model

Finite automaton

Reads one symbol at a time and changes finite state.

Cannot rewrite input or revisit arbitrary stored information.

Turing machine

Adds an effectively infinite tape and a read/write head.

Can write symbols and move left or right.

finite automaton + external read/write memory = Turing machine

The conceptual bridge

How neurons implement an automaton

Use one neuron (or bit pattern) to represent each state:

  • Et=1: currently even
  • Ot=1: currently odd
  • It: current input symbol
Ot+1=(Et AND It) OR (Ot AND NOT It)
Et+1=(Et AND NOT It) OR (Ot AND It)
Feed the state outputs back as inputs at the next time step. That feedback creates finite memory: a recurrent network.
